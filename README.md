# Sanika Parge — Cloud & DevOps Portfolio

A responsive dark portfolio website with subtle animations, project cards, skills, and contact links.

## Files
- `index.html` — page content and sections
- `style.css` — responsive layout and visual styling
- `script.js` — typing animation, mobile navigation, scroll reveal

## Run locally
Open `index.html` in a browser, or run a simple local server from this directory:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize before publishing
1. Verify your project links and update them if needed.
2. Add your resume PDF and connect the hero button if you want a resume download.
3. Add screenshots or live demo links for projects that are fully deployed.
4. Avoid listing tools or project features you cannot explain in an interview.

## Publish with GitHub Pages
1. Create a repository on GitHub, for example `sanika-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site and open the provided URL.
